# Fix-CampusWiFi 校园网自动修复

> 一键诊断 + 自动修复 + 持续守护, 针对校园网"网速差 / 老掉线 / 网页打不开"的常见根因。
> 双击即用, 无需安装。

## 特性

- **掉线自动重连** — SSID 丢失时自动用已保存的校园网配置重连
- **信号弱自动漫游** — 检测附近更强的 AP 并强制切换 (优先 5GHz, 避开 2.4GHz 拥塞)
- **公网不通自动续 IP** — 自动 release/renew + 清 DNS 缓存, 应对 Portal 掉线/租约失效
- **持续守护模式** — 每 15 秒复查一次, 按 Q 退出
- **网卡省电优化** — 关闭 LPR/DTIM 省电休眠导致的周期性卡顿 (Intel 网卡)
- **TCP 自动调优修复**、**公共 DNS 切换 (自动备份+自动回滚)**、**IPv6 黑洞修复**、**协议栈重置**
- **全面诊断** — 只读体检 7 项, 输出问题清单与修复建议
- **真实测速** — Cloudflare 20MB 下载测速, 记录到 CSV 用于对比晚高峰拥塞

## 环境要求

- Windows 7/10/11, PowerShell 5.1+ (系统自带)
- 部分功能 (Tune/TcpFix/DnsFix/IPv6/ResetStack) 需要管理员权限, 右键 **以管理员身份运行**
- 无线网卡 (Intel 网卡可享受更多优化项)

## 快速开始

双击 `Fix-CampusWiFi.bat` 即进入守护模式 (掉线自动重连 + 信号弱漫游 + 公网不通续 IP, 每 15 秒复查, 按 Q 退出)。

或命令行使用:

```bat
powershell -ExecutionPolicy Bypass -File Fix-CampusWiFi.ps1 -Once
```

## 参数一览

| 参数 | 作用 | 权限 |
|---|---|---|
| *(无参数)* | 守护模式: 持续自动修复 | 普通 |
| `-Once` | 诊断+修复一次后退出 | 普通 |
| `-NoFix` | 仅诊断, 不做任何修复 | 普通 |
| `-Diagnose` | 全面体检 7 项 (省电/频段/TCP/DNS/时延/丢包/IPv6), 只读 | 普通 |
| `-SpeedTest` | 真实下载测速, 记入 speedlog.csv | 普通 |
| `-RenewIP` | 释放/续 IP + 清 DNS 缓存 | 普通 |
| `-Tune` | 关闭网卡省电 + 激进漫游 | **管理员** |
| `-Untune` | 恢复 -Tune 前的网卡设置 | **管理员** |
| `-TcpFix` | 启用 TCP 自动调优 (autotuning=systemnormal) | **管理员** |
| `-DnsFix` | 切公共 DNS 223.5.5.5/119.29.29.29, 自动备份+失败自动回滚 | **管理员** |
| `-DnsRestore` | 恢复原 DNS | **管理员** |
| `-FixIpv6` | 禁用 WLAN 上的 IPv6 (应对 IPv6 黑洞) | **管理员** |
| `-UnFixIpv6` | 恢复 WLAN 的 IPv6 | **管理员** |
| `-ResetStack` | 重置 IP 协议栈 + Winsock, 需重启 (核选项) | **管理员** |

## 修复覆盖的问题

1. 网卡 LPR/DTIM 省电休眠 → 周期性卡顿
2. 停在 2.4GHz 拥塞频段 → 自动强制漫游 5GHz
3. TCP 自动调优被关/受限 → 吞吐低
4. 校园 DNS 慢/挂 → 切公共 DNS 并自动回滚
5. IP 租约失效 / Portal 掉线 → 自动 release/renew
6. 校园 IPv6 黑洞 → 可禁用 WLAN 上的 IPv6
7. 协议栈损坏 → 核选项重置 (需重启)
8. 晚高峰出口拥塞 / AP 侧问题 → 诊断定位 + 测速日志

> 说明: 学校出口带宽/AP 覆盖/需手动 Portal 登录的问题, 脚本会如实提示"这是学校侧问题", 不会假装能修。

## 兼容性设计

- 基于 **值解析** (信号含 %、RSSI 为负数、BSSID 是 MAC、速率为整数) 读取 netsh 输出, 与系统语言无关
- 自适应探测无线适配器名 (中文系统 "WLAN" / 英文 "Wi-Fi")
- 重建连接/IP 变化时自动提醒可能需要重新登录校园网 Portal
